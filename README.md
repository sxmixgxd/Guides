# Quartz v5

> [!WARNING]
> Quartz v5 is currently in active development. The API is unstable and subject to change.

Quartz is a fast, batteries-included static-site generator that transforms Markdown content into fully functional websites. Thousands of students, developers, and writers use Quartz as both a free, open-source alternative to Obsidian Publish and more.

Documentation and a live demo available at https://quartz.jzhao.xyz/
